# Envanter Web Sayfaları — Mobil Port Dokümantasyonu

Kaynak: `purchase-fe` (`App.tsx` + ilgili pages/components/services)

**Capability özeti**
| Capability | Permission |
|---|---|
| `INVENTORY_VIEW` | `INVENTORY_READ` veya `INVENTORY_UPDATE` |
| `INVENTORY_MANAGE` | `INVENTORY_UPDATE` |

**Ürün tipi davranış matrisi (kritik)**
| Tip | Seri stock item | Miktar zimmeti | Manuel stok mode |
|---|---|---|---|
| `FIXED_ASSET` / `IT_HARDWARE` | Evet | Hayır | `serial` |
| `SEMI_FIXED_ASSET` | Hayır | Evet | `semi` |
| `CONSUMABLE` / `OFFICE_SUPPLIES` / diğer | Hayır | Evet | `quantity` |

Konum seviyeleri: **1=Üst konum**, **2=Alt konum**, **3=Detay konum**

## ProductList

- **Route + CapabilityRoute:** `/products` — `PrivateRoute` + `INVENTORY_VIEW`
- **Tip:** list
- **Amaç:** Tüm ürünleri filtrele, sırala, sayfala; detay/düzenle/klon/sil/etiket/zimmet aksiyonları

### Filtreler (`ProductListFilters`)
**Hızlı arama:** ad, kod, kategori, etiket, seri no, sipariş no, not, okul, model, durum, tedarikçi, IP/MAC…

**Genel:** kategori, ürün tipi (ALL + CATEGORY_PRODUCT_TYPE_OPTIONS), kayıt durumu (ALL/ACTIVE/INACTIVE)

**Demirbaş:** şirket, marka, model (markaya bağlı; marka değişince model sıfırlanır), cihaz durumu, demirbaş etiketi (Etiketli/Etiketsiz), üst/alt/detay konum (kademeli; üst değişince alt+detay sıfırlanır), BYOD, stok kalemi durumu (IN_STOCK/ASSIGNED/IN_USE/MAINTENANCE/RETIRED), zimmet/kullanım (CAN_ASSIGN/IN_USE/NOT_ASSIGNABLE)

**Sipariş & fiyat:** tedarikçi, sipariş no, min/max tahmini fiyat, min/max satın alma, birim, sırala (name/code/price/purchasePrice/createdAt) + ↑↓

**UI:** Filtrele toggle, ActiveFiltersBar chip’ler, sayfa başına 10/20/50/100, client-side pagination

### Tablo kolonları (`ProductListPanel`)
Görsel | Ürün (ad+kod+tip) | Etiket | Seri no | Model | Kategori | Stok/Zimmet | Konum | İşlemler (sticky)

### Butonlar/aksiyonlar
- Filtrele, Yeni Ürün (`INVENTORY_MANAGE` → `/products/create`)
- Satır tık → detay
- Zimmetle (`canAssign` → `/products/:id?assign=1`), Detay, Klonla, Düzenle, Etiket bas, Sil (`INVENTORY_MANAGE`)

### APIs
- `productService.getAllProducts` → `GET /api/products`
- `categoryService.getActiveCategories` / `getAllCategories`
- `schoolService.getActiveSchools`, `supplierService.getActiveSuppliers`
- `inventoryService.getDeviceModels`, `getAssetConditions`, `getParentLocations`, `getChildLocations`
- `locationService.getAllLocations` → `GET /api/locations`
- Sil: `DELETE /api/products/:id`

### Edge cases
- Filtre client-side; tüm ürünler tek seferde çekilir
- `?assign=1` ProductDetail’de zimmet modalını otomatik açmaz (URL okunmuyor — web’de gap)
- Boş filtre sonucu özel empty message

### Görüntülenen alanlar

### Butonlar
Geri, Düzenle (`INVENTORY_MANAGE`), Zimmet Et (`product.canAssign`; blocker listesi)

### APIs
- `GET /api/products/:id`, `GET /api/products/:id/procurement`
- Stok: `GET /api/v1/stock-items/product/:id` (serial) veya `GET /api/warehouse-stocks/product/:id` → fallback `.../detail`
- `GET /api/v1/assignments/product/:id`
- `POST /api/v1/assignments`, form/photo/signed/return/cancel endpoints
- `DELETE /api/products/:id/suppliers/:supplierId`
- Users/schools masters

### Edge cases
- `canAssign=false` → amber blocker listesi
- Sarf boş stok: “manuel giriş yapın”; demirbaş: “Hazır + depo”
- Quantity zimmet: stok aşımı engeli; warehouseId zorunlu
- Serial zimmet: `stockItemId` gönderilir; quantity tipte warehouse+quantity
- İade/iptal sonrası stok+ürün yenilenir
- Resim lightbox modal

## Mobil port için kritik notlar

1. **Serial vs quantity** ayrımı tüm zimmet/stok UI’ını belirler — tek form yetmez.
2. **Product create flow:** depo seç → stokta bekle; depo yok → create+assignment atomik.
3. **Asset condition lock:** zimmetliyken durum değiştirilemez; önce iade.
4. **Zimmet belge zinciri:** foto → form download → imzalı xlsx → (iade: return form + foto + imzalı + depo).
5. **Warehouse/Stock sayfaları** CapabilityRoute kullanmıyor; mobil’de yetki modelini netleştirin.
6. **LocationList/Create butonları** UI’da MANAGE kontrolü eksik; route korumalı.
7. **ProductList `?assign=1`** web’de zimmet modalını açmıyor; mobil’de deep-link tanımlanmalı.
